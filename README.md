YouTube Trending Videos Analytics

Project Overview

This project analyzes trending YouTube videos across different countries to understand video performance, popular categories, title sentiment, and trending duration.

Project Objectives

- Analyze video performance across countries.
- Identify popular video categories.
- Explore views, likes, and engagement.
- Analyze sentiment in video titles.
- Study how long videos remain trending.

Tools and Technologies

- Python: Data cleaning and analysis
- Pandas and NumPy: Data manipulation
- VADER Sentiment Analysis: Title sentiment classification
- SQL (SQLite): Data querying and summarization
- Tableau: Data visualization and dashboard creation
- Google Colab: Python notebook environment

Project Workflow

1. Collected country-wise YouTube trending video datasets.
2. Loaded and inspected the data using Python.
3. Cleaned the data and handled data quality issues.
4. Analyzed country performance, categories, title sentiment, and trending duration.
5. Prepared summary CSV files.
6. Used SQL queries to explore and summarize data.
7. Created visualizations and KPI cards in Tableau.
8. Combined the visualizations into a dashboard.

Key Analysis Areas

- Country-wise video performance
- Category-wise views
- Video title sentiment
- Trending duration

Project Files

Project files include the Python notebook, Tableau dashboard, analysis output files, and project report.

Conclusion

This project provided practical experience in data cleaning, exploratory data analysis, SQL querying, sentiment analysis, and dashboard development. It demonstrates how data analytics tools can be used to explore YouTube trending video patterns.

Note: Sentiment analysis is approximate, especially for titles in multiple languages.
